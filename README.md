# DiskScope

DiskScope is a command-line disk space analyser built using Rust. It aims to help users understand how storage is being used by identifying large files, analysing directories and displaying useful storage statistics.

## Features

### Current Features
- Command-line application written in Rust.
- Welcome screen displaying application information.
- Version information retrieved from Cargo.

### Planned Features
- Recursive directory scanning.
- File and folder size calculations.
- Human-readable storage units (KB, MB, GB).
- Sorting and filtering files.
- Duplicate file detection.
- Storage usage statistics.
- JSON and CSV report exports.
- Terminal progress indicators.

## Technologies

- **Language:** Rust
- **Build System:** Cargo
- **IDE:** IntelliJ IDEA
- **Version Control:** Git and GitHub
